# Zachman CSV Data

## Format
The initial dataset is stored as cell-level rows (not as a rigid 6x6 grid file).

File(s):
- `zachman_matrix_cells.csv`

CSV Columns:
- `row`: Zachman framework row label (e.g., `Planner`, `Owner`, etc.)
- `column`: Zachman framework column label (e.g., `What`, `How`, etc.)
- `cell`: Text describing the cell content (may be empty for placeholders)

## Notes
- The sample CSV included here is a minimal starter set. Replace or extend with your full Zachman matrix content as needed.
